## Summary

This guide shows how to find a seller identifier depending on the marketplace so you can use Vallax's **follow/ignore sellers** feature.

## From Vallax

This is the easiest option. Vallax notifications include a button that lets you copy the seller identifier directly.

<figure>
  <img
    src="/posts/follow_users/get_seller_id.jpg"
    alt="Vallax notification with the seller identifier highlighted"
    width="360"
  />
</figure>

Once you tap that button, the identifier will be copied to your clipboard and you can paste it into Vallax.

## Vinted

Open the seller profile in Vinted. The identifier appears at the end of the URL.

<figure>
  <img
    src="https://vallax.es/posts/follow_users/vinted_url.png"
    alt="Vinted profile showing the seller identifier at the end of the URL"
    width="720"
  />
</figure>

## Todocoleccion

The process is almost the same as Vinted: open the seller profile and copy the identifier from the URL.

<figure>
  <img
    src="https://vallax.es/posts/follow_users/todocoleccion_url.png"
    alt="Todocoleccion profile showing the seller identifier in the URL"
    width="720"
  />
</figure>

## Milanuncios

In Milanuncios you also need to open the seller profile and check the URL. Copy only the numeric identifier.

<figure>
  <img
    src="https://vallax.es/posts/follow_users/milanuncios_url.png"
    alt="Milanuncios profile showing the numeric seller identifier in the URL"
    width="720"
  />
</figure>

## Wallapop

Wallapop is a bit more manual. Follow these steps:

1. Go to the seller profile.
2. Open the browser inspector with right click and choose **Inspect**.

<figure>
  <img
    src="https://vallax.es/posts/follow_users/foto_click_inspeccionar.png"
    alt="Browser context menu with the Inspect option on Wallapop"
    width="720"
  />
</figure>

3. In the inspector, use the search box and type `"userId"` including the quotes.
4. Press `Enter` and locate the value associated with the seller identifier.

<figure>
  <img
    src="https://vallax.es/posts/follow_users/user_id_zoom.png"
    alt="Browser inspector searching for userId in a Wallapop profile"
    width="720"
  />
</figure>

<figure>
  <img
    src="https://vallax.es/posts/follow_users/user_id_value_zoom.png"

  />

Note: these examples were made with Firefox. In Chrome, some elements may appear in a different place, but the idea is the same.

## Conclusion

You now know how to get the **seller identifier** on every supported marketplace so you can **follow or ignore** sellers in Vallax depending on your needs.
